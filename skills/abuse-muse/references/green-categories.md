# Green categories

Classify a green task by its main intent, so each task fits one category and the three categories together cover green use.

## Learn

- Summarize public articles, videos, textbooks, and documentation, and turn them into flashcards and study guides.

- Explain a public concept, and compare public products, prices, routes, guides, and datasets, with no account, date, or payment tied to the user.

## Build

- Install, configure, and fix open source and public software using public documentation and example values only.

- Debug a generic error with identifiers removed, and write a script for a public problem.

## Create

- Build templates for budgets, projects, resumes, emails, checklists, and workouts using placeholders instead of real amounts and names.

- Practice a language, brainstorm a generic idea, and draft a story or outline for invented people, places, and companies.

## Classification rule

- Use the main intent, not every possible secondary use, to assign a category.

- Move a task out of green when it adds a real person, a real account, a real location, or a real payment detail.
