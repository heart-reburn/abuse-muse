# Revealed clues tracker

Copy this file to `~/.abuse-muse/revealed-clues-tracker.md` and fill in that copy. Never commit the filled-in copy, sync it to cloud storage, or put it anywhere Muse can read it.

## Rules for this file

- Write clue types only. Never write a value, name, place, date, prompt, or chat.
- Not allowed: accountant, New York, hiking, a company name, a school name.
- Allowed: job, city, hobby.
- If you're not sure whether something is a type or a value, treat it as a value and don't write it.
